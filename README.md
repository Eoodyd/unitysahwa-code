# unitysahwa-code

Unitysahwa-refactoring-with-claudecode(before) 프로젝트에서 `Assets/Scripts` 코드만 커밋 히스토리와 함께 분리한 저장소임.
리팩토링 이전 버전 코드임. 씬, 프리팹, 에셋 등 실행에 필요한 리소스는 포함 안 됨.

## 개발 환경
- Unity 2022.3.62f2

## 폴더 구조
`Assets/Scripts` 바로 아래 폴더 목록임.

- Camera
- Enemy
- Gimmick
- Interface
- Manager
- Object
- Player
- Struct
- Timeline
- UI
